# Asset-Management-App

To install dependencies for backend, navigate to the 'Backend' folder in terminal and run:
```
pip install -r requirements.txt
```

## How to run the project
**Start Backend server**
1. Navigate to top-level 'Backend' folder in terminal.
2. Run the command `python manage.py runserver`. Note that you might have to use `python3` instead, depending on your OS.

**Start Frontend server**
1. Navigate to top-level 'Frontend' folder in terminal.
2. Run the command `npm start`
